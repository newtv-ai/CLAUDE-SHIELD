## 📖 项目简介

在 2026 年，Anthropic (Claude) 的反欺诈风控系统在封号机制上大幅收紧，不仅核验您的代理出口 IP 纯净度，还会比对您的浏览器指纹、DNS 泄露轨迹、本地物理网卡暴露的 WebRTC IP，以及本地操作系统的时区/语言一致性。

**Claude Shield** 是一款纯前端实现的本地环境穿透核验系统。通过零后端依赖的轻量化设计，多维度检测您的电脑环境是否安全，在您登录 Claude 或使用 Claude Code (命令行工具) 之前发出风险预警，将“秒封”风险降到最低。

### 🔎 五大核心审计指标

1. **IP 信誉与托管画像**：评估当前代理 IP 的欺诈分值（Fraud Score）及连接类型（Residential / Datacenter），判断其是否已被机房黑名单标记。
2. **DNS 穿透泄露测试**：自动发送临时测试解析包，检测您的海外代理是否泄露了本地（如中国境内）的 DNS 解析服务器，防止风控穿透。
3. **WebRTC 网卡泄漏轨迹**：扫描浏览器 ICE 候选人，核验其是否透过代理直接泄露了您真实的局域网内网 IP 或物理公网 IP。
4. **系统指纹环境一致性**：自动比对本地系统时区、首选语言是否与当前代理出口 IP 所属地理位置对齐（例如：IP 在美国，但时区是中国，即判定为高风险）。
5. **TLS 传输层指纹评估**：捕获并模拟 JA4 客户端指纹特征，核验浏览器客户端请求在反爬虫特征中的拟合度。

## 🚀 两种一键代理及防泄露安全启动方案

本项目在根目录下提供了两种同等安全、支持一键将环境变量注入系统以**同时保护三个工具（Claude Code、Antigravity、Codex）**的环境配置与启动方案：

> [!IMPORTANT]
> **📢 使用脚本的前提条件**
> 本项目所提供的所有防封锁脚本和工具，其发挥作用的前提是：**您所使用的 VPS / 代理节点 IP 本身必须是纯净且未被 Anthropic 列入黑名单的。**
> 只有当 VPS 出口 IP 良好，仅由于您本地电脑的“东八区时区”、“中文语言设置”或“WebRTC 物理 IP 泄露”导致风控检测异常时，本方案才能完美为您锁定环境指标，将封号风险降到最低。如果节点 IP 本身已在黑名单中，任何本地指纹伪装都无济于事。

---

### 🔑 方案 A：SSH 安全隧道模式（一键脚本）
**适用场景**：适合不想连通本地第三方客户端软件，或者追求极致轻量、直接通过 VPS IP 进行网络连接的开发者。

#### 💻 VPS 服务端配置要求（几乎为零）
* **无需安装任何代理软件**：您的 VPS 内部**完全不需要**安装任何如 Clash、v2ray 或 Shadowsocks 等代理服务。脚本底层利用 SSH 服务原生的“动态端口转发”特性。只要您的 VPS 支持普通的 SSH 连通即可。
* **极罕见排查点**：如果出现 SSH 连接成功但代理隧道建立失败，请登录您的 VPS，编辑 SSH 配置文件 `/etc/ssh/sshd_config`，确保 `AllowTcpForwarding` 选项为 `yes`（系统默认即为 `yes`）：
  ```text
  AllowTcpForwarding yes
  ```
  若做了修改，需重启 SSH 服务以生效（如运行 `systemctl restart ssh`）。

#### 📋 使用说明（Windows 环境）
1. 双击运行 **`setup_proxy_env.bat`**，初次使用时按提示输入 VPS 链接配置。
2. 脚本会后台静默拉起 SSH 隧道，并自动将防泄露变量注入 Windows 用户的**全局环境变量注册表**。
3. **全系统无感激活**：此时新开的任何命令行、PowerShell 窗口或 VS Code 终端均会自动进入防泄露保护。您无需再做任何选择，直接在此类新窗口中运行 `claude`（启动 Claude Code）、或者敲入 Antigravity 和 Codex 的启动命令，它们将**全部且同时**被完美代理与锁定防卫！
4. 开发完毕，双击运行 **`restore_proxy_env.bat`** 断开隧道并彻底清除 Windows 全局用户环境变量，一秒还原直连网络。

#### 📋 使用说明（Linux / macOS 环境）
* 运行命令 `source ./setup_proxy_env.sh`（使用 `source` 让环境变量注入当前终端），后台 SSH 隧道自动拉起。在此终端会话中运行上述三大工具中的任何一个或全部，将直接受保护生效。
* 开发结束，运行 `bash ./restore_proxy_env.sh` 关闭隧道并释放代理。

### 📡 方案 B：本地已有代理客户端模式（快捷脚本）
**适用场景**：适合您的电脑上已经运行着如 **v2rayN、Clash、Shadowsocks** 等代理客户端，且您的 VPS 节点已配置在该软件中的场景。该模式可以**免去建立 SSH 隧道的繁琐，也无需输入 VPS 密码**，直接桥接您已有的科学上网通道。

#### 💡 核心安全配置原理
很多开发者习惯直接开着代理客户端运行 `claude` 等命令行，这往往会因**本地 DNS 请求未走代理**引发 DNS 本地穿透泄露，或因**时区不一致**被风控标记。
本方案通过将终端代理地址强制锁定为 **`socks5h://`** 协议，强行命令本地程序将域名解析包也打包发送给您本地的客户端，由客户端通过海外节点执行远程 DNS 解析，从而彻底解决 DNS 穿透泄露。

#### 📋 使用说明（Windows / Unix 环境）
1. 确保您的代理客户端（如 v2rayN）已启动且正常工作。
2. 找到您客户端监听的 **SOCKS5 本地端口**：
   * **v2rayN 用户**：直接查看客户端最底下一行状态栏，会显示类似 `SOCKS5 127.0.0.1:10808`，其中 `10808` 即为端口。
   * **Clash 用户**：在 General 界面查看 `Socks Port`（默认通常是 `7890`）。
3. 运行根目录下的启动脚本：
   * **Windows**：双击运行 **`run_claude_via_v2ray.bat`**。
   * **Linux / macOS**：使用 `source ./run_claude_via_v2ray.sh` 或 `./run_claude_via_v2ray.sh` 运行。
4. 按提示输入刚才获取的本地 SOCKS5 端口（直接回车默认采用 v2rayN 默认端口 `10808`），并按回车确认 VPS 所在的 IANA 时区（默认 `America/New_York`）。
5. **一键注入与终端保持**：脚本会自动配置当前终端的代理防线与时区锁。配置完成后，脚本**不会强制您做单选，也不会自动关闭，而是直接将当前终端保持在激活交互状态（安全隔离沙盒终端）**。
6. 您可以直接在该终端中，输入并启动您的任何开发或 AI 协作工具：
   * 运行 Claude Code：直接输入 `claude`
   * 运行 Antigravity：直接输入您的 Agent 启动命令
   * 运行 Codex：直接输入您的 Agent 启动命令

## 🛠️ 项目本地部署运行

本项目检测面板基于 **Vite + SvelteKit + TypeScript** 构建，用于核验方案 A/B 配置后各指标是否确实完全对齐：

1. **克隆并安装依赖**：
   ```bash
   npm install
   ```
2. **启动本地核验网页**：
   * **Windows**：双击运行根目录下的 `start.bat`。
   * **Linux / macOS**：赋予执行权限后运行 `./start.sh`。
3. **浏览器体验**：
   * 访问本地地址：`http://127.0.0.1:5173/` 进行环境审计。
